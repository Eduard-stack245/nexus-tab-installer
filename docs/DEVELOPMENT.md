# Разработка Nexus Tab Installer

Программа на Python и Flet плюс расширение браузера. Здесь описано устройство проекта.

## Быстрый старт

```bash
py -3 -m pip install -r requirements-dev.txt
py -3 -m pytest
START_WINDOWS.bat
```

- `PYTHONPATH` для тестов не нужен: путь задан в `pyproject.toml`. То же делает `scripts/run_tests.bat`.
- После правки расширения нажмите круглую стрелку на его карточке на `edge://extensions`.
- Отдельная папка данных: переменная `NEXUS_TAB_HOME`. Настоящие настройки и архивы лежат в `data/`.
- Запуск с другой папкой данных создаёт новый токен. Расширение переживает это и сохраняет старый ключ.

## Карта кода

| Путь | Что там |
|---|---|
| `src/nexus_tab_installer/ui/flet_app.py` | Контроллер: состояние, обработчики кнопок, цикл `process_queue` |
| `ui/views.py` | Экраны без своей логики |
| `browser/auto_free.py` | Очередь заданий браузера: выдача, повторы, пауза, аренда |
| `browser/pacing.py` | Темп: паузы, предел за сутки, откат при неудачах и ограничениях |
| `browser/import_server.py` | Локальный HTTP-сервер для расширения, порт 38471 |
| `browser/tab_snapshots.py`, `windows_tabs.py` | Списки вкладок от расширения и средствами Windows |
| `core/links.py` | Разбор ссылок, сохранение `file_id` |
| `core/workflow_session.py` | Состояние пакета, учёт каждого файла (`expect` / `finish`) |
| `core/trace.py` | Журнал диагностики с белым списком событий |
| `downloads/queue.py`, `transfer.py` | Очередь загрузок и докачка по HTTPS |
| `integrations/delivery.py` | Передача архива в библиотеку, MO2, Vortex или игру |
| `nexus/api.py` | Nexus API v1 |
| `extensions/*/background.js` | Подключение к программе и список вкладок |
| `extensions/*/auto_download.js` | Задания, окно-помощник, перехват загрузки |
| `extensions/*/auto_free_content.js` | Действия на странице Nexus |

## Как проходит загрузка

1. «Скачать выбранные» → `prepare_downloads` выбирает файлы каждого мода. Приоритет:
   выбор вручную, затем `file_id` из вкладки или ссылки, затем последний MAIN.
   Каждый файл становится задачей `game:mod:file`; `file` = 0 значит «определит страница».
2. Premium с ключом идёт в `DownloadQueue` через API. Остальное идёт в `AutoFreeBatch`.
3. Расширение опрашивает `/auto/next`. Следующее задание выдаётся, только когда
   очередь загрузок пуста (`auto_free.gate`: подписанные ссылки живут недолго)
   и подошло его время (`auto_free.pacer`).
4. Расширение открывает страницу файла, скрипт нажимает кнопку сайта и ждёт его отсчёт.
5. `downloads.onCreated` ловит загрузку: отменяет её в браузере и передаёт ссылку программе.
6. Запасные пути:
   - загрузка не замечена за 6 секунд: берётся ссылка «Start download manually» со страницы;
   - CDN ответил программе 401, 403 или 410: файл сохраняет браузер (режим `browser`);
   - API отказал: файл передаётся браузеру.
7. После загрузки файл доставляется (`deliver`), и `finish_if_done` завершает пакет,
   когда не осталось незавершённых задач.

## Протокол расширения и программы

Заголовок `X-Nexus-Token` нужен везде, кроме `/health` и `/pair/*`.

| Запрос | Назначение |
|---|---|
| `GET /health` | Программа запущена |
| `POST /pair/request`, `GET /pair/status` | Первое подключение, подтверждается в программе |
| `POST /snapshot` | Список вкладок с модами |
| `GET /auto/next` | Следующее задание, `active`, `wait` (секунд до возможного задания), `scan_marker` (запрос свежего списка вкладок). Заголовок `X-Nexus-Extension`: версия расширения |
| `GET /auto/status?job_id=` | Состояние задания, по нему расширение останавливает страницу |
| `POST /auto/complete` | `progress`, `url`, `file`, `failed` или `nxm` |
| `POST /diagnostics/event` | Событие журнала |

## Что зависит от сайта Nexus

Сайт меняется, и чаще всего ломаться будет это место. Минифицированные имена в его
скриптах меняются между сборками, поэтому опираться на них нельзя.
Всё ниже находится в `auto_free_content.js`:

- элементы `<mod-file-download>` и `<mod-download-modal>`, поиск идёт сквозь shadow root;
- атрибуты `file-id`, `user-is-premium`, `timeout-seconds`;
- тексты `Slow download`, `Start download`, `Standard download`, `Start download manually`,
  `Your download will start in`, а также тексты ошибок в `siteError` и `siteRefusal`;
- список файлов: `#file-container-main-files dt[data-id]`, `data-date`.

Если сайт изменился, поправьте и `tests/browser_check/fake_nexus.py`: имитация должна повторять настоящий сайт.
Настоящие страницы ограничения Nexus ещё не наблюдались. Увидите такую страницу — добавьте её текст в `LIMIT_TEXT`.

Как разбирать поломку: вкладка «Журнал» или файл `data/logs/download-trace.jsonl`.
Смотрите последнее событие `extension.page.*`; `download.ignored` содержит причину отказа.

Каталоги CDN-ссылок — шестнадцатеричные байты UUID файла (`d7/97/69/…`), а не номера игры и мода.
Не выводите из цифр пути ничего: на этом уже была ошибка, файл ошибочно отвергался.

## Правила проекта

- **Скрипты расширения.** Весь код расширения совпадает в `extensions/chromium` и `extensions/firefox`,
  различаются только `manifest.json`. Это проверяет тест. Правьте один файл и копируйте во второй.
  Версию меняйте в обоих `manifest.json` и в `REQUIRED_EXTENSION` (`browser/auto_free.py`).
- **Журнал.** Новое событие или причину добавляйте в белые списки `core/trace.py`, иначе
  сервер отклонит событие; тест проверяет имена событий. Ссылки, ключи, cookie и имена файлов
  в журнал не пишутся.
- **Сайт.** Только кнопки сайта и его отсчёт. CAPTCHA, маскировка автоматизации, имитация человека
  и пропуск отсчёта запрещены: вход и проверку выполняет пользователь. Новые автотесты не должны
  обращаться к настоящему nexusmods.com, для этого есть имитация.
- **Интерфейс.** Элементы Flet меняются только в `process_queue` и обработчиках кнопок.
  Сеть и диск — через `background()`, результат приходит в очередь `incoming`.
- **Данные.** `data/` содержит API-ключ и токен расширения и исключён в `.gitignore`.
  Не передавайте эту папку другим людям.

## Тесты

- `tests/test_ui_end_to_end_v400.py` запускает настоящий `flet_app.main` без окна. Тест играет
  роль расширения по HTTP, а загрузчик подменён. Новые сценарии удобнее всего добавлять сюда.
- `tests/test_ui_pace_v410.py`: темп, сигналы сайта и перезапуск через тот же контроллер.
- Многие старые тесты проверяют наличие строк в исходниках, поэтому после переименования
  могут падать без реальной поломки.
- **`tests/browser_check`: настоящее расширение в настоящем браузере.** Обычный `pytest` их пропускает.
  Запуск: `scripts\check_browser.bat edge` или `chrome`, `opera-gx`, `firefox` (около 2 минут). Браузер получает
  временный профиль, адреса Nexus перенаправлены на локальную имитацию `fake_nexus.py`. Настоящий сайт и ваш
  профиль не затрагиваются. Настройки: `NEXUS_BROWSER_PATH` задаёт путь к неустановленному браузеру,
  `NEXUS_BROWSER_VISIBLE=1` показывает окна, `NEXUS_BROWSER_PROMPT=1` включает вопрос «куда сохранять».
- Opera GX кладёт свою стартовую вкладку первой в каждое новое окно, а запрос на её закрытие может не завершиться
  никогда. Поэтому вкладка файла ищется по адресу, а закрытие ограничено по времени (`settle` в `auto_download.js`).
- Запуск браузеров описан в `launchers.py`. Chromium получает адреса флагом, Firefox идёт через локальный прокси и
  получает расширение по Marionette. Обычный Chrome новых версий может отказать в `--load-extension`, поэтому
  проверялся Chrome for Testing с официального сайта Google.
- Не запускайте проверки программы с другой папкой данных на порту 38471, пока открыт настоящий браузер:
  его расширение обратится к этой копии.

## Как передать программу другому человеку

```bash
py -3 scripts/make_package.py
```

Появится `dist/NexusTabInstaller-<версия>-portable.zip`, около 75 МБ: программа работает из него без установки.
Внутри `runtime/python` (официальный встраиваемый Python и пакеты) и `runtime/flet` (окно программы, путь к нему
`flet_app.run` передаёт через `FLET_VIEW_PATH`). Сборка требует Python 3.14 и интернета. Новую версию Python нужно
прописать в `PYTHON_VERSION` и `PYTHON_SHA256`: сумма берётся со страницы выпуска на python.org.

`python314._pth` содержит только относительные пути, а настройки хранят пути внутри папки относительными
(`portable_path`, `saved_path`). Новые настройки с путями внутри папки сохраняйте так же, иначе перенос папки их сломает.

Файлы программы попадают в архив только по белому списку `INCLUDE`: папок
`data/` и `tests/` там нет, а сборка прервётся, если ваш ключ или токен окажется в файле программы.
Пересобирайте архив после каждого изменения и добавляйте в список новые файлы вне `src/` и `extensions/`.

## Firefox: постоянная установка

Временное дополнение исчезает при перезапуске Firefox. Чтобы оно осталось, расширение нужно подписать:
создайте аккаунт на addons.mozilla.org, замените идентификатор `nexus-tab-collector@example.invalid` в
`extensions/firefox/manifest.json` на свой, сожмите содержимое папки в ZIP и загрузите как «On your own»
(без публикации в каталоге). Полученный `.xpi` ставится навсегда. Подпись делается с вашего аккаунта,
автоматизировать её без него нельзя.

## Если программу будут получать другие люди

[Правила API Nexus](https://help.nexusmods.com/article/114-api-acceptable-use-policy) требуют регистрировать
программы для пользователей и запрещают использовать в них личный API-ключ разработчика. У каждого
пользователя должен быть свой ключ. Заголовок `Application-Version` должен совпадать с версией программы
(`nexus/api.py`). Автоматические нажатия на сайте Nexus могут не одобрить при регистрации, а раздел 11 условий
использования запрещает автоматические программы. Решите это с Nexus до распространения.

## Что дальше

Не проверено на настоящем сайте (CAPTCHA намеренно только предупреждение: её проходит человек):

- настоящие страницы проверки и ограничения Nexus (смоделированы в `fake_nexus.py`);
- файлы больше 500 МБ и сохранение файла браузером (проверены на имитации);
- Premium-аккаунт;
- скачивание в Chrome, Firefox и Opera GX (проверены на имитации, Opera GX ещё и на странице Nexus без входа).

Что можно улучшить:

- **Структура:** разделить `flet_app.py` (около 2600 строк) на контроллеры.
- **Магазины:** публикация расширения, пока оно ставится вручную.

## Выпуск версии

1. Версия меняется в `pyproject.toml`, `APP_VERSION` (`nexus/api.py`), `USER_AGENT` (`downloads/transfer.py`) и в двух местах
   `ui/flet_app.py`. Версия расширения: оба `manifest.json` и `REQUIRED_EXTENSION`.
2. Запись в `CHANGELOG.md`.
3. `py -3 -m pytest`, затем `py -3 scripts/make_package.py`.
4. Коммит, метка `vX.Y.Z` и выпуск на GitHub с архивом из `dist/`.

## Язык

Тексты в коде пишутся по-русски, как раньше. Английский лежит в `ui/lang_en.py`, а `ui/i18n.py` накладывает его там, где текст выходит на экран: всё уходит через
`redraw()`. Новый текст добавляйте в оба места, иначе `tests/test_language_v450.py` назовёт, что пропущено. Сообщение, собранное из кусков, переводится по предложениям.
Логика не должна читать `.value` текста на экране: для этого есть `source_text(control)`, которая вернёт текст программы на любом языке.

## Данные Nexus без ключа

`nexus/graphql.py` спрашивает открытый API: один запрос на 50 модов и не чаще раза в секунду. Он нужен только для удобства, поэтому его ошибка никогда не должна мешать
скачиванию. Тесты подменяют его в фикстуре `launch`, настоящая сеть в них не участвует.
